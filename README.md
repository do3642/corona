# 코로나 맵 (Corona Map)

### 📌 **프로젝트 개요**  
COVID-19 국내 및 국외 데이터를 시각화하여 제공하는 맵 기반 웹 애플리케이션입니다.  
이 프로젝트는 Flask를 활용하여 서버를 구축하고, 데이터 시각화와 사용자 친화적인 UI를 제공합니다.

---


### 📋 **기업 요구사항**
코로나19 국내외 재감염률 분석웹 개발


**1. 공공기관 및 다양한 유관기관에서 아직 종결되지 않은 코로나19에 대한 국내 외 재감염률에 대한 데이터 분석**
	- 감염률 중심의 분석과 시각화를 구현하였습니다.

**2. 지역별, 연령별로 코로나 재감염률 비율 분석**
	- 공공기관 및 유관기관의 데이터를 기반으로 지역별, 연령별 감염률 비율을 분석합니다.

**3. 공공데이터 활용**
	- 공공 데이터를 활용하여 코로나19 관련 정보의 분석과 예측 제공합니다.

## 🚀 **기능 소개**

### **국내 COVID-19 데이터 시각화**
- **데이터 분석**  
  - 각 지역별 인구수 비례 코로나 발병률, 사망률, 완치율 비율 시각화  
  - 연령대별 코로나 발병률,연령대별 사망률 중 확진자에 해당하는 사망률 분석
- **종합 통계 제공**  
  - 각 지역별 전체 확진자 및 사망자 누적 수  
  - 월별 평균 확진자 수와 사망자 수 제공  
- **보건소 정보 활용**  
  - 국민안심병원 및 선별진료소 현황 데이터를 기반으로 관련 정보 제공  
- **연령별 인구 데이터 연계**  
  - 연도별 연령별 인구 데이터를 활용하여 지역 및 연령대별 감염률 비교  
- **관련 뉴스 제공**  
  - 각 지역과 연관된 최신 뉴스 기사 표시  

### **국외 COVID-19 데이터 시각화**
- **글로벌 현황 제공**  
  - 전 세계 일간 데이터(어제, 오늘, 내일) , 누적 데이터 표기  
- **날짜별 국가별 현황**  
  - 특정 날짜에 따른 각국의 감염 데이터 및 감염 비율 분석  
- **기간별 통계 제공**  
  - 국가별 일간, 주간, 월간 감염 추세를 **파이, 막대, 라인 그래프**로 시각화  
- **관련 뉴스 제공**  
  - 각 국가와 연관된 최신 뉴스 기사 표시

## 📜 **설치 및 실행 방법**

### 1. 프로젝트 클론
`git clone https://github.com/do3642/corona.git`  
클론 후 `develop` 브랜치 확인

### 2. 가상환경 설정 및 활성화
가상환경 생성  
```bash
py -3.11 -m venv CoronaScope  
```

가상환경 활성화 (corona폴더인지 입력 주소확인)  
```bash
.\CoronaScope\Scripts\activate
```

### 3. 필수 패키지 설치
```bash
pip install -r requirements.txt
```


---

### 4. MySQL 데이터베이스 설정
MySQL에서 `coronamap` 데이터베이스를 생성합니다.  
(dbeaver 등 직접 생성해도 됨 (id:root /  pw:1234))
```bash
mysql -u root -p 1234
CREATE DATABASE coronamap;
```

### 5. 데이터베이스 마이그레이션
만약 `migrations` 폴더에 에러가 발생할 경우, 해당 폴더를 삭제하고 아래 명령어들을 순서대로 입력하여 마이그레이션을 적용합니다.
```bash
flask db init
flask db migrate
flask db upgrade
```



### 6. 환경 변수 설정 (.env)
.env 파일은 민감한 정보를 보호하기 위해 사용됩니다. 아래는 필요한 환경 변수 목록입니다:

- **.env 파일 ** - 루트폴더에 위치함 (corona/.env)
```python
 FLASK_APP=apps.app.py
FLASK_DEBUG=True
```

⚠️ .env 파일은 .gitignore에 포함되어 있어 GitHub에 업로드되지 않습니다.

---

### 7. 애플리케이션 실행
```bash
flask run
```

### 8. 데이터 저장
국외 페이지에 접근하기 전에, 아래 3개의 URL을 차례대로 호출하여 데이터베이스에 데이터를 저장해야 합니다.
(입력 후 worldwide>views.py에 해당 라우터 비활성화 권장)

- `http://localhost:5000/worldwide/insert-data`
- `http://localhost:5000/worldwide/insert-trans-data`
- `http://localhost:5000/worldwide/insert-latlong-data`

이 URL들을 통해 각종 데이터를 DB에 저장한 후, 국외 페이지에서 데이터를 정상적으로 조회할 수 있습니다.
